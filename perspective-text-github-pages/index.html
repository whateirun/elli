표지판 원근 글씨 합성기

표지판 모서리는 한 번 맞춰 저장하고, 이후에는 문장만 바꿔 PNG로 내려받으세요.

1. 문장과 글씨

글씨는 표지판 전체를 억지로 채우지 않습니다. 문장이 짧으면 최대 크기를 유지하고, 길어지면 표지판 안에 들어오도록 자동으로 작아집니다.

2. 표지판 영역 설정

파란 점을 표지판 네 모서리에 맞추세요. 설정은 이 브라우저에 자동 저장되어 다음 접속에도 유지됩니다.

● 모서리 설정이 이 브라우저에 저장됩니다.

3. 저장

다운로드는 원본 크기 1080 × 1080 PNG입니다. 조절점은 저장 이미지에 포함되지 않습니다.
